## 各版本 / 迭代详情

### v0.1.0 — 初始提交（2026-06-10）
- 初始化 SmartResume：AI 驱动的简历优化系统骨架。

### v0.2.0 — 核心功能重大更新（2026-06-18）
- **4 种 PDF 输出方案**：专业分栏 / 简约单栏 / LaTeX / 保留原样式（pdf_styler 多策略）。
- **我的信息一键优化**、岗位库（分类收藏）、简历库管理。
- 个人中心、仪表盘、管理员后台、模板选择下拉框。
- 后端：统一模板引擎 resume_renderer、text_formatter、API 路由修复、OptimizedResume 可空化。
- 前端：双优化按钮模板选择、岗位库页面、错误/加载/404 页面。

### v0.3.0 — 多模板 + Playwright PDF（2026-07-11）
- 新增 6 种中文简历模板：现代渐变 / 紧凑高效 / 优雅金边 / 深色科技 / 清新绿意 / 经典黑白。
- 模板预览弹窗组件 TemplateSelector（10 种方案可视化选择）。
- **PDF 渲染改用 Playwright（Chromium）替代 WeasyPrint**，解决 Windows 下 GTK3 依赖问题。
- 修复 Windows ProactorEventLoop 不支持子进程问题（SelectorEventLoopPolicy）。

### v0.4.0 — iOS 设计语言外壳（2026-09-11）
- 引入 iOS 设计 token 与手写组件库（src/components/ios/*，9 个组件）。
- **移除 VIP / 付费功能**（营销位、会员分类、财务菜单、付费接口与类型）。
- AppLayout 由桌面侧边栏改写为 iOS 外壳（NavBar + TabBar + 「更多功能」抽屉），后纠正为网页端 iOS 风外壳：左侧玻璃侧边栏 + 顶部毛玻璃导航条 + 宽屏内容区。
- 侧边栏导航项 hover 背景溢出修复、去除链接下划线。

### v0.5.0 — 优化停止 / 前后对比 / ATS / 面评（2026-09-17）
- **手动「停止优化」入口**，点击立即中断并保留上次结果。
- 完成前后对比弹窗：匹配度变化、变化摘要、章节级「修改前 → 修改后」对照。
- 差异算法识别关键词同源改写，避免误报「移除技能」。
- 新增 **ATS 检测、PDF/Word 导出、面评准备**等模块与验证脚本。
